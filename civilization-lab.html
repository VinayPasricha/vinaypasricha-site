Ask the manuscript. It answers only from the book — or refuses.

Local prototype over … chunks of the Civilization draft. The point is the refusal behaviour, and the experiment is the retriever: switch between keyword (lexical) and semantic (an in-browser MiniLM embedding model) and run the same battery in each. Same gate, same threshold slider — only the instrument changes.

The threshold is disposable. Keyword scores share-of-vocabulary; semantic scores cosine similarity of meaning. Both scales are throwaway — production will use a different embedding model. What's permanent is the refusal log, especially false refusals (the manuscript answers it, the gate refused). That's the calibration set. The semantic run exists to answer one question: does meaning-based retrieval cleanly separate the borderline paraphrases from off-topic questions where keyword retrieval could not?
