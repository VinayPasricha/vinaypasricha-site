# RUNTIME NODE 08

# Multi-Scale Systems Chamber

---

## Purpose

The runtime studies execution across **four scales**: individual, team, organization, mission. Constraints at one scale propagate to others. A solo-scale bottleneck (the executor's ambiguity tolerance) creates downstream org-scale fragmentation. A mission-scale ambition exceeds team-scale carrying capacity.

This chamber surfaces these cross-scale forces.

## Primitive Shape

**Nested scale layers.** Four concentric ring-zones, from inner to outer:

- **Individual** (center, smallest ring) — the executor alone.
- **Team** — the operating group around them.
- **Organization** — the larger system.
- **Mission** — the multi-year ambition.

Elements (forces, constraints, capacities) live at a specific scale. **Cross-scale links** — radial lines crossing scale boundaries — show propagation. Friction at a link encodes the strain of the propagation.

## Phase Progression

* observe → name forces at each scale,
* link → name cross-scale propagations,
* surface → identify the dominant cross-scale dynamic,
* settled → structural stillness.

## Atmosphere

Networked cognition. Layered. Wider than Constraint, deeper than Capacity. Breath 11.2s.

## Detection

* Which constraint at which scale is producing the most cross-scale distortion?
* Which scale carries the load that another scale generates?
* Which scale's ambition exceeds which scale's capacity?

## Final Constitutional Role

The Multi-Scale Systems Chamber preserves **scale-honest diagnosis** — distinguishing forces that originate at the individual from forces that originate at the team / org / mission.
