Studio / Transport

The layer where a message actually leaves.

Communication transport beneath the capability layer. Email-first (SMTP / SendGrid / SES / Gmail adapters); WhatsApp / SMS / LinkedIn are honest not_configured placeholders. Every outbound carries a thread token so replies route back automatically; delivery is tracked as events; threads and the audit trail update on every event. No real provider wired → blocks honestly. A simulate adapter exercises the full flow for testing, always labelled as simulated.
