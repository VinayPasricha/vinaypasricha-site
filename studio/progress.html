— What this is

A weekly or monthly check-in where you log the numbers that matter — visitors, subscribers, book sales, social follower counts, sessions completed. Each entry is a snapshot in time. The trend over time is what the dashboard shows.

Values are entered manually for now. When a backend is added, individual metrics can be wired to live sources (YouTube Data API, Plausible, Amazon KDP) one at a time — the schema doesn't change. See the colophon at the bottom for what each source requires.

— What each source requires

Plausible / GA — script tag on every page + their dashboard. Read API exists for Plausible. ~$6-9/month for a small site.

YouTube Data API v3 — free, channel-level stats are public. Per-video analytics need OAuth as channel owner.

Instagram Graph API — requires Business/Creator account + linked Facebook Page + OAuth. Free.

Amazon KDP — no public sales API. Reports must be exported manually from KDP dashboard.

LinkedIn / X — restricted or paid. Manual entry is the realistic path.

All automated fetches require server-side credentials (CORS + key safety). Pure client-side from the Studio is not possible — a small backend is required to bridge.
