— How this works

Each conversation on the site has a system prompt that shapes how the AI behaves. Edit them here. Saved drafts apply to your browser immediately so you can test. Publish & download writes a fresh prompts.json that you drop into the repo to deploy to all visitors.

Leaving a system field empty makes the conversation fall back to the inline default baked into the JS files. That is the safe state.
