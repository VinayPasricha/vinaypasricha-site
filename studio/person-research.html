Studio / Person Research

Start from a LinkedIn URL — honestly.

The front door to candidate intelligence. Enter a LinkedIn URL or a name + company and the runtime opens a research request, then reuses the Person Intelligence engine to build a preliminary brief, a preliminary frequency, and — against a target role/mandate — a lightweight resonance screen with a next action. It does not fetch the web or scrape LinkedIn; it asks you to paste real public material.

Honest by construction. Live web search and LinkedIn scraping are NOT IMPLEMENTED — a URL is stored, never scraped, and every public-evidence slot is marked manual input required until you paste real text. Pasted sources feed the same Person Intelligence engine; the screen is a recruiter aid only — no score, no ranking, no fit %, no hire/reject decision, no automated contact.
