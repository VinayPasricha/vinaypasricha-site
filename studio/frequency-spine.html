One frequency. Everything else translates through it.

Architecture Review 1.0 found the worst crack in the system: two frequency vocabularies that don't agree — twelve dimensions measured in Public Intelligence and Validation, a different ten reasoned about in Mission, Evolution, and Learning. So Current → Mission → Gap was partly apples-to-oranges, and three dimensions the mission layer relies on were never measured. This is the canonical basis that fixes it: a single set of dimensions both vocabularies map into, with the never-measured ones made explicit and clearly marked derived — a bridge, never a silent invention.

This room is the source of truth for what a dimension is. It does not modify any profile, mission, or path — the working layers keep their own vocabularies and translate through this spine. The crosswalk shows every mapping; the derivation rules show exactly how an unmeasured dimension is bridged (and why it carries lower confidence); the gap demo recomputes Current vs Mission in one shared space. This sets up X2 — Confidence & Provenance: once a value knows whether it was measured or derived, confidence can finally carry its own evidence.
