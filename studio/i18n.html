— How this works

Each language pack is a JSON file at assets/data/i18n/<lang>.json. When a visitor sets ?lang=hi, the pack loads instantly — no per-visitor AI calls. Strings missing from the pack fall back to live Claude translation (slower, per-browser cache).

Two-step workflow: Discover crawls every public page and extracts translatable strings. Translate via AI sends untranslated ones to Claude in batches. Then review, edit any line, publish.
