Subscribers

— Honest note about scope

Every email captured by the site \u2014 Notebook subscribes, book-notify forms, AION1 intake completions \u2014 currently lives in the visitor's own localStorage. This room can only see captures made in this browser.

That's a deliberate v1 trade. Once the backend (see _brief/backend-plan.md) is wired, this same room will read from a real database and every capture will be visible. The data shape stays identical, so the UI doesn't change \u2014 only the data source does.
