Public Intelligence · organizational frequency from a URL
Consumes the 3A research queue — only selected companies. From a company's URL it assembles public signals, estimates an Organizational Frequency across twelve dimensions, maps contradictions, and drafts an SEO-ready public profile page (slug, title, meta, JSON-LD) in careful, probabilistic language. Live providers honest-blocked; manual public-source import works. Pages are marked ready for review, never auto-published; no outreach, no validation, no ratings.

xxviii.
Validation · public estimate → validated understanding
The layer between Public Intelligence and Deep Discovery. Opens a validation campaign against a 3B public page, identifies stakeholders (Apollo honest-blocked; CSV / manual work), and generates questions only from gaps — low-confidence dimensions, contradictions, unknowns, unvalidated claims — each pointing to a specific hypothesis. Records responses, moves confidence, and writes a history-preserving evolution event for every change. Profile climbs Public Estimate → Partially → Leadership → Multi-Stakeholder → Living. Purpose is accuracy, not sales.

xxix.
Mission & Gaps · what the organization must become
Takes the 3C validated profile as Current Frequency, derives the Mission Frequency a stated mission actually requires (from the mission's own language), and computes the gap between them across ten dimensions. Then names the constraints blocking the gap — contested dimensions, centralized decisions, strained culture, unvalidated unknowns — and the priority recommendations to close it. Organizational moves toward the mission, not hiring. Honest about weak evidence: sparse input reads low-confidence, never false certainty.
— missions · — gaps

xxx.
Evolution · how the organization evolves toward its mission
Takes the 3D gap analysis and turns each gap into a plausible pathway — 1–5 sequenced milestones per gap, ending in a validation step that closes the loop back to stakeholders. Tracks the real changes as they happen: progress per dimension (current → target), trend, and what remains unresolved. Every recorded change writes a Frequency Evolution event — history preserved, never overwritten. It does not transform the organization; it observes, models, tracks, and learns. No project management, hiring, or outreach.
— paths · — milestones

xxxi.
Learning · what we observe across all organizations
The first cross-organizational layer. It reads the evolution paths, events, and outcomes of every tracked company and extracts recurring patterns — which sequences accompany improvement, which shapes precede failure, where the evidence contradicts itself. Confidence is a function of sample size and consistency, tracked over time with history preserved. An observer: never claims causation, never modifies a profile, never hides a contradiction. Turns recommendations from expert opinion into observed organizational learning.
— observations · — patterns

xxxii.
Frequency Spine · one canonical basis · foundation · Build X1
The consolidation layer from Architecture Review 1.0. Resolves the system's worst crack — two frequency vocabularies (12-dim in Public Intelligence & Validation, a different 10-dim in Mission, Evolution & Learning) that made Current → Mission → Gap apples-to-oranges. Defines one canonical basis (15 dimensions, 6 families) both vocabularies translate through, normalizes every level string onto a shared scale, and makes the three never-measured dimensions (adaptability, learning, risk tolerance) explicit and honestly derived. The other rooms translate through it; it modifies nothing. Sets up X2 — Confidence & Provenance.
